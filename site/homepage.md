# מוריד מסמכים אצווה — נט המשפט

תוסף Chrome לעורכי דין, מתמחים ובעלי דין המנהלים תיקים בנט המשפט.

## מה התוסף עושה

מאפשר להוריד בלחיצה אחת מספר רב של פריטים מתוך תיק — בלי להוריד כל אחד בנפרד — תוך כדי שימוש בסשן המאומת הקיים שלך, מבלי לעקוף שום הזדהות.

## מסמכים

- סימון מסמכים מתוך כל תיקייה בתיק: החלטות, בקשות, כתבי טענות, תצהירים, פסקי דין, פרוטוקולים, מוצגים ותיק נייר.
- "סמן הכל בעמוד" או "סמן הכל בכל העמודים" — התוסף עובר על עמודי הדפדוף עבורך.
- הורדה כקובץ **ZIP יחיד** עם קובץ אינדקס **CSV** (שם קובץ, סוג מסמך, תאריך, מגיש, מספר עמודים, מקור).
- כל מסמך נבנה כ-PDF מעמודי המסמך, בתוך הדפדפן.
- תיקים גדולים מתפצלים אוטומטית לכמה קובצי ZIP; ניתן לבטל באמצע, ואם הסשן פג — להתחבר מחדש ולהמשיך מאותה נקודה.

## דיונים ויומן

- הורדת רשימות דיונים (גם במצב "הדיונים שלי" עם טווח תאריכים) כ-CSV וכקובץ **ICS** לייבוא לכל יומן.
- אפשרות לסנכרן את הדיונים ישירות ל-**Google Calendar** — אירוע לכל דיון, בלוח שנה שתבחר, עם תבנית כותרת/מיקום/תיאור הניתנת להתאמה.

## יעדים גמישים

- **הורדה מקומית** (ZIP) — ברירת המחדל.
- **שרת API אישי** — שליחת כל קובץ ל-endpoint שתגדיר, עם כותרת `X-API-Key`.
- **Google Drive** — העלאה לתת-תיקייה לפי מספר התיק ושם הרשימה, עם בורר תיקיות מובנה, יצירת תיקייה חדשה, ומניעת כפילויות (העלאת חדשים בלבד).

## פרטיות

ברירת המחדל היא מקומית לחלוטין — אין שרת ביניים, אין אנליטיקס ואין מעקב. יעדי שרת/Drive/יומן פועלים רק אם הפעלת אותם בעצמך ועם הפרטים שלך. ראו [מדיניות פרטיות מלאה](https://www.z-g.co.il/court-downloader/privacy).
