# מוריד מסמכים אצווה — נט המשפט (גרסה רזה / Lite)

תוסף Chrome להורדת מספר מסמכים מתיק בנט המשפט (`securesso.court.gov.il`)
כקובץ **ZIP אחד** עם קובץ אינדקס. גרסה זו היא **רזה**:

- ✅ הורדת מסמכים בלבד (החלטות, בקשות, כתבי טענות, תצהירים, פסקי דין, פרוטוקולים, תיק נייר…)
- ✅ הורדה מקומית למחשב בלבד (ZIP)
- ❌ ללא דיונים / יומן
- ❌ ללא שליחה לשרת (API)
- ❌ ללא Google Drive
- ❌ ללא הגדרות

**פרטיות:** כל העיבוד מתבצע במחשב שלך, בתוך הדפדפן. שום מסמך לא נשלח לאף שרת חיצוני. התוסף משתמש בהזדהות הקיימת שלך בנט המשפט בלבד.

---

## איך לטעון את התוסף בכרום (התקנה ידנית)

מכיוון שהתוסף לא מותקן מחנות Chrome, טוענים אותו ידנית במצב מפתח. פעם אחת:

1. **פתח את עמוד התוספים**
   הקלד בשורת הכתובת:
   ```
   chrome://extensions
   ```
   ולחץ Enter.

2. **הפעל "מצב מפתח" (Developer mode)**
   מתג בפינה הימנית־עליונה של העמוד → העבר אותו ל־**ON**.

3. **לחץ "Load unpacked" (טען לא ארוז)**
   כפתור שיופיע בפינה השמאלית־עליונה אחרי הפעלת מצב מפתח.

4. **בחר את התיקייה הזו**
   נווט אל התיקייה:
   ```
   chrome-extension-lite
   ```
   (התיקייה שמכילה את הקובץ `manifest.json`) → **Select Folder**.

5. **זהו** — התוסף יופיע ברשימה עם האייקון "נ". מומלץ להצמיד אותו לסרגל הכלים:
   לחץ על אייקון הפאזל (🧩) ליד שורת הכתובת → נעץ את "מוריד מסמכים אצווה".

---

## איך משתמשים

1. היכנס/י לנט המשפט והזדהה/י כרגיל (כרטיס חכם / SSO).
2. פתח/י תיק → בחר/י תיקיית מסמכים בצד (למשל **"החלטות בתיק"**).
3. מעל טבלת המסמכים יופיע פס כחול: **"📥 הורדת מסמכים"**.
4. סמן/י מסמכים (תיבות הסימון הכחולות בכל שורה), או לחץ/י **"סמן הכל"**.
5. לחץ/י **"הורד ל־ZIP"**.
6. ה־PDF־ים נבנים ויורדים כקובץ ZIP אחד (עם `index.csv`). בתיקים גדולים ההורדה
   מתפצלת אוטומטית לכמה קבצי ZIP. אפשר לבטל באמצע (הכפתור הופך ל"בטל").

> אם פג תוקף הסשן באמצע — התחבר/י מחדש לנט המשפט ולחץ/י "הורד ל־ZIP" שוב.

---

## עדכון התוסף
אם מחליפים את קבצי התיקייה בגרסה חדשה — חזור/חזרי ל־`chrome://extensions`
ולחץ/י על כפתור הרענון (⟲) בכרטיס של התוסף, ואז רענן/י את עמוד נט המשפט.

## הסרה
ב־`chrome://extensions` → "Remove" בכרטיס התוסף.
